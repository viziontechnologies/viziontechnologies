How to install an Android app from here

  1. Tap Download on the app you want. The APK file saves to your phone.
  2. Open the file from the download notification, or from Files → Downloads.
  3. If Android asks, allow your browser or Files app to install apps. You can switch this off again afterwards.
  4. Tap Install, then Open. Updates install the same way, over the old version, and keep your data.

Every APK here is signed by Vizion Technologies and served from our public GitHub releases, where each version lists its SHA-256 checksum. Because these apps aren't from the Play Store, Android may show a warning before installing. Stuck? Message us on WhatsApp and we'll help.
